## 四、宴席行业高频痛点库

```
P01. 菜品缩水：签合同时一个标准，实际上菜时分量和质量明显缩水
P02. 临时换菜：说好的菜因"食材问题"临时替换，还不提前告知
P03. 服务人员不够：高峰时段服务跟不上，宾客叫人没人应答
P04. 布置临时缩减：婚宴布置效果和谈判时的方案相差甚远
P05. 加价套路：基础套餐价格低，各类加收项目（酒水开瓶费/布置费）叠加后超出预算
P06. 协调混乱：同一天多场宴席，各场之间发生冲突，场地/人员/时间撞车
P07. 售前和售后两张脸：谈的时候全程陪同，签完合同找不到人
P08. 停车/动线问题：宾客找不到路，停车位不够，影响宾客体验
P09. 现场突发不处理：出了问题推诿责任，不主动解决
P10. 菜品口味不稳：同一个套餐，不同场次味道差距大，厨师状态影响品质
```

## 五、宴席行业口吻规范

**整体基调：** 稳重、细致、有担当感，像一个经验丰富、靠谱的老管家

**服务细节要具体到动作：**
- 正确："婚宴当天，我们有一个人专门站在停车场入口做引导，不是指一下方向，是全程带到停车位，再带回宴会厅门口"
- 错误："我们提供全方位周到服务，让每位宾客感到宾至如归"

**危机处理要展示解决方式：**
- 正确："有一次宴席开始前两小时，主婚纱出了问题。我们联系了3家供应商，最后在40分钟内解决了。那对新人到现在还是我们的常客"
- 错误："无论遇到什么情况，我们都会尽力解决"

**场景描述要有仪式感和细节感：**
- 正确："宴席开始前半小时，每一张桌子上的花都是重新摆过的。不是因为有规定，是因为我知道宾客进来的第一眼很重要"
- 错误："精心布置每一个细节，打造完美宴会氛围"

**禁止词：**
- 尽善尽美/宾至如归/完美体验/高端定制/奢华享受/专业团队保驾护航

**宴席类特殊要求：**

- 服务幕后类：要有"准备过程"的镜头，而不只是成果展示
- 案例类：说具体宴席（婚宴几桌/寿宴什么规格），不说泛泛的"承办过众多宴席"

## 七、质量硬标准

- [ ] 场景类内容：让人产生"想在这里办"的具体感受
- [ ] 痛点类内容：说的是真实存在的问题，解决方案是主理人真的在做的
- [ ] 案例类内容：有具体细节（时间/规格/关键转折），不是泛泛案例
- [ ] 无豪华感营造（重细节，轻排场）
- [ ] 总口播字数150-180字（不超过180字，这是1分钟视频标准量）
- [ ] 结尾按类型：故事/幕后/教育/观点/氛围型→自然收尾；互动型→可有问句；整组最多8条有结尾引导
