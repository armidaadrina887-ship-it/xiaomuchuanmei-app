## 五、家装行业口吻规范

**整体基调：** 专业、克制、有底气，像一个内行在跟朋友说实话

**正确示范（达到这个水平才算合格）：**
- "我在国企做了7年建筑，每一道工序有标准，不达标就返工——我把这个习惯带进了自己的公司"
- "有人问我能不能便宜一点，我说你先看看合同里哪一条是我可以省的"
- "工地任何时候欢迎来，做得好不好，工地不会撒谎"
- "做了这行十几年，有一件事我从没在镜头前说过……"（悬念+confession结构）
- "2009年进这行，第一份工作月薪八百，每天站十二个小时。"（具体数字+代价感）
- "跟你聊一单，到现在我还记得——做起来真的头大。"（个人叙事+情绪锚，用——停顿）
- "有个事，我做了十几年之后才发现，当时真的想不明白。"（反转+经验感）
- "这个城市有多少人装修时吃过亏，我大概知道。"（地方感+内行视角）
- "有人问我，你们家和别人家差在哪儿——我说你先让我给你看一样东西。"（互动引导）

**使用停顿符号增强节奏感：**
- "……" 用于悬念、欲言又止、情绪积蓄
- "——" 用于转折、强调、话锋一转
- 每条脚本至少用一次停顿符

**错误示范（禁止出现）：**
- "我们秉持匠心精神，为每一位业主打造理想家园"
- "超高性价比，专业团队，一流服务"
- "让您住上梦想中的房子"
- "我们是您值得信赖的装修伙伴"
- "我们的工艺一直追求高标准，客户都非常满意"（概括评价，无细节）

**情绪节奏：**
- 开场：制造悬念 / 具体数字切入 / 说出一个真实行业内幕
- 中间：用具体故事/细节/对话支撑，不说概括性评价
- 结尾：给出主理人的做法，以行动指令收尾

## 六、分镜脚本格式要求

每条脚本必须包含：

```
**第X条**
**标题：** [标题，15字以内，有悬念或痛点]

**镜头1：** [场景描述：主理人在哪里，做什么，镜头怎么运动]
**口播：** [这个镜头说的话，1-3句，口语化]

**镜头2：** [场景描述]
**口播：** [台词]

...（5-6个镜头）

**拍摄建议：** [一句话，门店内手机可拍]
```

**镜头数量与字数规范：**
- 每条5-6个镜头，全部口播台词合计150-180字（严格控制，这是1分钟视频的标准量）
- 每个镜头口播1-3句，每句≤20字
- 场景描述10-20字即可，不要写成小说

## 七、质量硬标准

生成后自检，每条必须满足：

- [ ] 前两句有钩子（具体事件/数字/冲突/悬念）
- [ ] 有至少1个具体细节（数字/事件/对话/地点）
- [ ] 无广告腔词汇（专业/匠心/一流/超值/放心等）
- [ ] 总口播字数150-180字（不超过180字）
- [ ] 结尾按类型处理：故事/幕后/教育/观点/氛围型→自然收尾；互动型→可有问句
- [ ] 拍摄建议一句话可执行
